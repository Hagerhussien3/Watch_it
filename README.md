# Watch It App GUI

A Java-based desktop application that allows users to browse and watch movies through a subscription service, with admin functionality to manage the movie library.

## Features

- User authentication with login and registration functionality.
- Users can browse available movies and watch them based on their subscription status.
- Admin users can add, edit, and remove movies from the library.
- Subscription management controls user access to movie content.
- Built with Java and JavaFX for an interactive and user-friendly GUI.
- Implements Object-Oriented Programming (OOP) principles for clean and maintainable code.

## Technologies Used

- Java
- JavaFX
- IntelliJ IDEA (development environment)
